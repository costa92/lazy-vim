# Neovim 导航和滚动快捷键指南

本文档列出了所有与导航、滚动相关的快捷键命令。

## 屏幕滚动

| 快捷键 | 功能描述 |
|--------|----------|
| `<Ctrl>d` | 向下滚动半屏 |
| `<Ctrl>u` | 向上滚动半屏 |
| `<Ctrl>f` | 向下滚动一整屏（Forward） |
| `<Ctrl>b` | ⚠️ 已被 Neo-tree toggle 占用，原功能：向上滚动一整屏 |
| `zz` | 将当前行移动到屏幕中央 |
| `zt` | 将当前行移动到屏幕顶部 |
| `zb` | 将当前行移动到屏幕底部 |

## 光标移动

### 基本移动
| 快捷键 | 功能描述 |
|--------|----------|
| `h` | 向左移动一个字符 |
| `j` | 向下移动一行 |
| `k` | 向上移动一行 |
| `l` | 向右移动一个字符 |
| `w` | 移动到下一个单词的开头 |
| `b` | 移动到上一个单词的开头 |
| `e` | 移动到当前单词的结尾 |
| `0` | 移动到行首 |
| `^` | 移动到行首第一个非空白字符 |
| `$` | 移动到行尾 |

### 行内跳转
| 快捷键 | 功能描述 |
|--------|----------|
| `f{char}` | 向后跳转到字符 {char} |
| `F{char}` | 向前跳转到字符 {char} |
| `t{char}` | 向后跳转到字符 {char} 之前 |
| `T{char}` | 向前跳转到字符 {char} 之后 |
| `;` | 重复上次的 f/t 命令 |
| `,` | 反向重复上次的 f/t 命令 |

### 文件内跳转
| 快捷键 | 功能描述 |
|--------|----------|
| `gg` | 跳转到文件开头 |
| `G` | 跳转到文件末尾 |
| `{number}G` | 跳转到指定行号 |
| `:{number}` | 跳转到指定行号 |
| `%` | 在括号间跳转 |
| `{` | 跳转到上一段落 |
| `}` | 跳转到下一段落 |

| `<Ctrl>k` | 跳转到上方窗口 |
| `<Ctrl>l` | 跳转到右侧窗口 |

## 移动行/文本

### 插入模式
| 快捷键 | 功能描述 |
|--------|----------|
| `<Alt>j` | 将当前行向下移动 |
| `<Alt>k` | 将当前行向上移动 |
| `<Ctrl>h` | 跳转到行首 |
| `<Ctrl>l` | 跳转到行尾 |

### 普通模式
| 快捷键 | 功能描述 |
|--------|----------|
| `<Alt>j` | 将当前行向下移动 |
| `<Alt>k` | 将当前行向上移动 |

### 可视模式
| 快捷键 | 功能描述 |
|--------|----------|
| `J` | 向下移动选中的文本 |
| `K` | 向上移动选中的文本 |

## 文件树导航 (Neo-tree)

| 快捷键 | 功能描述 |
|--------|----------|
| `<Ctrl>b` | 打开/关闭文件树 |
| `<space>e` | 在文件树中定位当前文件 |
| `H` | 切换显示/隐藏文件（在 Neo-tree 中） |

## 跳转列表

| 快捷键 | 功能描述 |
|--------|----------|
| `<Ctrl>o` | **跳转到上一个位置（返回）** ⭐ 最常用 |
| `<Ctrl>i` | 跳转到下一个位置（前进） |
| `` ` ` `` | 跳回到上次跳转前的位置 |
| `''` | 跳回到上次跳转前的行 |
| `:jumps` | 查看完整的跳转历史列表 |

### 使用示例
```
工作流程：
1. 在代码中按 gd 跳转到定义
2. 查看完定义后，按 Ctrl+o 返回原处
3. 可以连续按 Ctrl+o 回到更早的位置
4. 按 Ctrl+i 可以向前跳转
```

## 标记 (Marks)

| 快捷键 | 功能描述 |
|--------|----------|
| `m{a-z}` | 在当前位置设置标记 |
| `` `{a-z} `` | 跳转到标记位置 |
| `'{a-z}` | 跳转到标记所在行的开头 |
| `<space>m` | 搜索所有标记 (FZF) |

## 使用技巧

### 组合使用
1. **快速浏览代码**：
   - 使用 `Ctrl+d` 和 `Ctrl+u` 快速浏览
   - 看到有趣的内容时按 `zz` 居中显示

2. **精确定位**：
   - 使用 `/{pattern}` 搜索
   - 按 `n` 跳转到下一个匹配
   - 按 `N` 跳转到上一个匹配

3. **代码导航**：
   - 使用 `gd` 跳转到定义
   - 使用 `Ctrl+o` 返回原处 ⭐
   - 使用 `gr` 查看所有引用
   - 多次跳转后可以连续按 `Ctrl+o` 回退

4. **多窗口工作**：
   - `sv` 垂直分割
   - `Ctrl+h/j/k/l` 在窗口间快速切换
   - `so` 关闭其他窗口专注当前

### 注意事项
- `Ctrl+b` 原本是向上滚动一整屏，但在本配置中被 Neo-tree 占用
- 如果需要向上滚动一整屏，可以使用 `Ctrl+u` 两次
- 或者可以重新映射 Neo-tree 的快捷键
