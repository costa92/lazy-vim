# Neovim 导航和滚动快捷键指南

本文档列出了所有与导航、滚动相关的快捷键命令。

## 屏幕滚动

| 快捷键 | 功能描述 |
|--------|----------|
| `<Ctrl>d` | 向下滚动半屏 |
| `<Ctrl>u` | 向上滚动半屏 |
| `<Ctrl>f` | 向下滚动一整屏（Forward） |
| `<Ctrl>b` | ⚠️ 已被 Neo-tree toggle 占用，原功能：向上滚动一整屏 |
| `zz` | 将当前行移动到屏幕中央 |
| `zt` | 将当前行移动到屏幕顶部 |
| `zb` | 将当前行移动到屏幕底部 |

## 光标移动

### 基本移动
| 快捷键 | 功能描述 |
|--------|----------|
| `h` | 向左移动一个字符 |
| `j` | 向下移动一行 |
| `k` | 向上移动一行 |
| `l` | 向右移动一个字符 |
| `w` | 移动到下一个单词的开头 |
| `b` | 移动到上一个单词的开头 |
| `e` | 移动到当前单词的结尾 |
| `0` | 移动到行首 |
| `^` | 移动到行首第一个非空白字符 |
| `$` | 移动到行尾 |

### 行内跳转
| 快捷键 | 功能描述 |
|--------|----------|
| `f{char}` | 向后跳转到字符 {char} |
| `F{char}` | 向前跳转到字符 {char} |
| `t{char}` | 向后跳转到字符 {char} 之前 |
| `T{char}` | 向前跳转到字符 {char} 之后 |
| `;` | 重复上次的 f/t 命令 |
| `,` | 反向重复上次的 f/t 命令 |

### 文件内跳转
| 快捷键 | 功能描述 |
|--------|----------|
| `gg` | 跳转到文件开头 |
| `G` | 跳转到文件末尾 |
| `{number}G` | 跳转到指定行号（如：50G 跳到第 50 行）⭐ |
| `{number}gg` | 跳转到指定行号（如：50gg 跳到第 50 行） |
| `:{number}` | 跳转到指定行号（如：:50 跳到第 50 行，需按 Enter） |
| `{number}%` | 跳转到文件的百分比位置（如：50% 跳到文件中间） |
| `%` | 在括号间跳转 |
| `{` | 跳转到上一段落 |
| `}` | 跳转到下一段落 |
| `Ctrl+g` | 显示当前位置信息（行号、列号、文件百分比） |

### 快速跳转示例
```
50G      → 跳转到第 50 行（推荐）
:100     → 跳转到第 100 行
50%      → 跳转到文件中间位置
1G 或 gg → 跳转到文件开头
G        → 跳转到文件末尾
```

## 窗口跳转

| 快捷键 | 功能描述 |
|--------|----------|
| `<Ctrl>h` | 跳转到左侧窗口；若已在最左则聚焦 Neo-tree 侧栏 ⭐ |
| `<Ctrl>j` | 跳转到下方窗口 |
| `<Ctrl>k` | 跳转到上方窗口 |
| `<Ctrl>l` | 跳转到右侧窗口 |

> **`<Ctrl>h` 的 Neo-tree fallback**：`gr`（查看引用）会在底部打开**全宽 quickfix** 列表，
> 它横跨整个宽度、左侧没有窗口，此时普通的 `<C-w>h` 无法左移。本配置为 `<Ctrl>h` 增加了
> fallback：当已处于最左窗口（如引用列表所在的全宽 quickfix）时，改为聚焦 Neo-tree 文件树，
> 让你从引用列表一键跳回侧栏。在代码窗口中行为不变，仍是正常左移。

## 退出 Neovim

本配置在 `lua/configs/keymaps.lua` 中将 `<C-q>` 绑定为任意模式快速退出，配合 `<C-s>` 保存，可实现一键保存 + 一键退出。

### 常用退出命令

| 快捷键 / 命令 | 模式 | 功能描述 |
|--------|------|----------|
| `<Ctrl>q` | 所有模式 | **关闭当前窗口**（本配置自定义）⭐ 最常用 |
| `<Ctrl>s` | 所有模式 | 保存文件（配合 `<C-q>` 使用） |
| `:q` | 命令模式 | 关闭当前窗口（无未保存改动时） |
| `:q!` | 命令模式 | 放弃修改强制关闭当前窗口 |
| `:wq` | 命令模式 | 保存并关闭当前窗口 |
| `ZZ` | 普通模式 | 保存并退出（等价 `:wq`，两键搞定） |
| `ZQ` | 普通模式 | 不保存直接退出（等价 `:q!`） |
| `:qa` | 命令模式 | 关闭所有窗口退出 Neovim |
| `:qa!` | 命令模式 | 放弃所有修改强制退出 |
| `:wqa` | 命令模式 | 保存所有窗口并退出 |

### 使用场景

1. **日常退出**：直接按 `<C-q>`，本配置最顺手。
2. **先存后退**：`<C-s>` → `<C-q>`，两次按键完成保存并退出。
3. **多窗口 / 多 Tab 全部关闭**：用 `:qa` 或 `:qa!`，比连续按 `<C-q>` 更干脆。
4. **只关闭当前 split 保留其它**：普通模式 `sc`（参见"窗口分割"章节）。
5. **Neo-tree 面板同时开着**：建议用 `:qa`，否则可能需要多次按 `<C-q>` 逐个关闭窗口。

### 注意事项

- **`<C-q>` 在某些终端会被拦截**：部分终端默认启用软件流控（XON/XOFF），`Ctrl+q` 会被当作 XON 而无法传递给 Neovim。
  - 临时禁用：在 shell 中执行 `stty -ixon`
  - 永久禁用：把 `stty -ixon` 写入 `~/.zshrc` 或 `~/.bashrc`
  - 或在终端（iTerm2 / Alacritty / WezTerm 等）的快捷键设置中禁用流控
- **有未保存修改时 `:q` 会报错**：改用 `:q!` 强退或 `:wq` 保存退出；`<C-q>` 同样会被阻止，此时需要先 `<C-s>` 保存。

## 跳转列表

| 快捷键 | 功能描述 |
|--------|----------|
| `<Ctrl>o` | **后退：跳回上一个位置** ⭐ 与 `<Ctrl>i` 成对 |
| `<Ctrl>i` | **前进：再跳回 `<C-o>` 离开的位置** ⭐ 等价于 `<Tab>` |
| `` ` ` `` | 跳回到上次跳转前的位置 |
| `''` | 跳回到上次跳转前的行 |
| `:jumps` | 查看完整的跳转历史列表 |
| `<leader>fj` | **FZF 浏览 jumplist**（可模糊搜、带文件预览）⭐ |
| `g;` | 跳到上一个修改位置 |
| `g,` | 跳到下一个修改位置 |
| `3<C-o>` | 数字前缀：一次跳回 N 步 |

> **`<C-o>` ↔ `<C-i>` 往返**：`<C-o>` 后退、`<C-i>` 前进，是一对来回键（`<C-i>` 在终端等同 `<Tab>`）。
> 注意 `<C-i>` 只能沿"来时的路"前进：`<C-o>` 退回后若又产生了新跳转（再按 `gd`/`gr`、打开别的文件等），
> 前进历史会被截断，此时改用 `<leader>fj` 从完整 jumplist 里精确挑一条。

### 使用示例
```
工作流程：
1. 在代码中按 gd 跳转到定义
2. 查看完定义后，按 Ctrl+o 返回原处
3. 可以连续按 Ctrl+o 回到更早的位置
4. 按 Ctrl+i 可以向前跳转
5. 跨多文件深度回溯时：<leader>fj 打开 FZF 跳转历史，预览后精确跳

gr（查看引用）同理：
1. 在符号上按 gr，跳到某个引用
2. 看完/改完后按 Ctrl+o 跳回原来的符号处
3. 顺手用 <C-q> 或 :cclose 关掉底部的全宽 quickfix 引用列表
   （在该列表里按 <C-h> 可聚焦回 Neo-tree，见"窗口跳转"章节）
```

## 使用技巧

### 组合使用
1. **快速浏览代码**：
   - 使用 `Ctrl+d` 和 `Ctrl+u` 快速浏览
   - 看到有趣的内容时按 `zz` 居中显示

2. **精确定位**：
   - 使用 `/{pattern}` 搜索
   - 按 `n` 跳转到下一个匹配
   - 按 `N` 跳转到上一个匹配
   - 使用 `50G` 跳转到指定行号

3. **调试代码**：
   - 看到错误提示 "Error at line 142"
   - 按 `142G` 直接跳转到第 142 行
   - 修复后按 `Ctrl+o` 返回之前位置

4. **代码导航**：
   - 使用 `gd` 跳转到定义
   - 使用 `Ctrl+o` 返回原处 ⭐
   - 使用 `gr` 查看所有引用
   - 多次跳转后可以连续按 `Ctrl+o` 回退

5. **多窗口工作**：
   - `sv` 垂直分割
   - `Ctrl+h/j/k/l` 在窗口间快速切换
   - `so` 关闭其他窗口专注当前

### 注意事项
- `Ctrl+b` 原本是向上滚动一整屏，但在本配置中被 Neo-tree 占用
- 如果需要向上滚动一整屏，可以使用 `Ctrl+u` 两次
- 或者可以重新映射 Neo-tree 的快捷键
