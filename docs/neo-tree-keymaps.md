# Neo-tree 快捷键文档

Neo-tree 是一个文件浏览器插件，提供了丰富的功能和快捷键。本文档整理了所有可用的快捷键。

## 全局快捷键

| 快捷键 | 功能 |
|--------|------|
| `<C-b>` | 切换（打开/关闭）Neo-tree |
| `<leader>ee` | 打开 Neo-tree 并定位到当前文件 |

## 基本操作

| 快捷键 | 功能 |
|--------|------|
| `<space>` | 展开/折叠节点 |
| `<2-LeftMouse>` | 打开文件/目录 |
| `<cr>` (回车) | 打开文件/目录 |
| `<esc>` | 取消操作/关闭预览或浮动窗口 |
| `P` | 切换预览模式 |
| `l` | 聚焦到预览 |
| `S` | 在水平分割窗口中打开 |
| `s` | 在垂直分割窗口中打开 |
| `t` | 在新标签页中打开 |
| `w` | 使用窗口选择器打开 |
| `C` | 关闭节点 |
| `z` | 关闭所有节点 |

## 文件操作

| 快捷键 | 功能 |
|--------|------|
| `a` | 新建文件 |
| `A` | 新建目录 |
| `d` | 删除文件/目录 |
| `r` | 重命名文件/目录 |
| `b` | 重命名基本名称（不含路径） |
| `y` | 复制到剪贴板 |
| `x` | 剪切到剪贴板 |
| `p` | 从剪贴板粘贴 |
| `c` | 复制文件/目录到指定位置 |
| `m` | 移动文件/目录到指定位置 |
| `q` | 关闭窗口 |
| `R` | 刷新 |
| `?` | 显示帮助 |
| `<` | 上一个源 |
| `>` | 下一个源 |
| `i` | 显示文件详情 |

## 文件系统特定操作

| 快捷键 | 功能 |
|--------|------|
| `<bs>` (退格键) | 导航到上级目录 |
| `.` | 设置为根目录 |
| `H` | 切换隐藏文件的显示 |
| `/` | 模糊查找 |
| `D` | 目录模糊查找 |
| `#` | 模糊排序 |
| `f` | 提交过滤 |
| `<c-x>` | 清除过滤器 |
| `[g` | 上一个已修改的文件（Git） |
| `]g` | 下一个已修改的文件（Git） |

## 排序操作

| 快捷键 | 功能 |
|--------|------|
| `o` | 显示排序帮助 |
| `oc` | 按创建时间排序 |
| `od` | 按诊断信息排序 |
| `og` | 按 Git 状态排序 |
| `om` | 按修改时间排序 |
| `on` | 按名称排序 |
| `os` | 按大小排序 |
| `ot` | 按类型排序 |

## 缓冲区特定操作

| 快捷键 | 功能 |
|--------|------|
| `d` 或 `bd` | 删除缓冲区 |

## Git 状态特定操作

| 快捷键 | 功能 |
|--------|------|
| `A` | 添加所有文件 |
| `gu` | 取消暂存文件 |
| `ga` | 添加文件 |
| `gr` | 还原文件 |
| `gc` | 提交 |
| `gp` | 推送 |
| `gg` | 提交并推送 |

## Git 冲突管理

| 快捷键 | 功能 |
|--------|------|
| `:Gvdiffsplit!` | 打开三向合并视图（需安装 fugitive 插件） |
| `:diffget //2` | 使用左侧（本地）版本解决冲突 |
| `:diffget //3` | 使用右侧（远程/传入）版本解决冲突 |
| `]c` | 跳转到下一个冲突点 |
| `[c` | 跳转到上一个冲突点 |
| `:Gwrite` | 保存更改并将文件标记为已解决 |
| `:Git mergetool` | 打开合并工具解决冲突 |

## 模糊查找器中的快捷键

| 快捷键 | 功能 |
|--------|------|
| `<down>` 或 `<C-n>` | 向下移动光标 |
| `<up>` 或 `<C-p>` | 向上移动光标 |
| `<esc>` | 关闭 |

## 跳转操作

| 快捷键 | 功能 |
|--------|------|
| `gr` | 查看引用（在 LSP 支持下） |
| `<C-o>` | 跳回上一个位置（在使用 `gr` 后可用于返回） |
| `<C-i>` | 跳转到下一个位置 |
| `:jumps` | 显示跳转列表 |
