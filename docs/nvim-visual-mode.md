# Neovim Visual 模式与多选

Neovim 提供了强大的 Visual 模式，用于选择文本并对其执行操作。虽然它没有传统意义上的多光标编辑，但 Visual 模式，特别是块 Visual 模式，在很多场景下能实现类似的效果。

## Visual 模式类型

Neovim 主要有三种 Visual 模式：

1. **字符 Visual 模式 (Characterwise Visual Mode)**
    * **进入**: 按 `v`
    * **选择**: 按字符选择。
    * **用途**: 选择单词、短语等。

2. **行 Visual 模式 (Linewise Visual Mode)**
    * **进入**: 按 `V` (大写)
    * **选择**: 整行选择。
    * **用途**: 选择多行代码、段落。

3. **块 Visual 模式 (Blockwise Visual Mode)**
    * **进入**: 按 `<C-v>` (Ctrl + v)
    * **选择**: 选择矩形文本块。
    * **用途**: 最接近多光标编辑，用于列操作、批量插入/删除等。

## Visual 模式下的常用操作

进入任何 Visual 模式后，你可以使用各种命令对选中的文本进行操作：

| 命令 | 功能 |
|------|------|
| `d`  | 删除选中文本 |
| `y`  | 复制 (yank) 选中文本 |
| `c`  | 更改 (change) 选中文本 (删除并进入插入模式) |
| `>`  | 增加缩进 |
| `<`  | 减少缩进 |
| `=`  | 格式化选中文本 (需要格式化器) |
| `J`  | 合并所有选中行为一行 |
| `U`  | 将选中文本转换为大写 |
| `u`  | 将选中文本转换为小写 |
| `~`  | 切换选中文本的大小写 |
| `I`  | (块模式下) 在选中块的每行 *之前* 进入插入模式 |
| `A`  | (块模式下) 在选中块的每行 *之后* 进入插入模式 |
| `:'<,'>command` | 对选中区域执行 Ex 命令 (例如 `:'<,'>s/foo/bar/g` 替换) |

## 块 Visual 模式示例 (模拟多光标插入)

假设你想在下面几行的开头都插入 `#`：

```
line 1
line 2
line 3
```

1. 光标移动到 `line 1` 的行首。
2. 按 `<C-v>` 进入块 Visual 模式。
3. 按 `j` 两次向下移动光标，选中三行的行首。
4. 按 `I` (大写 I) 进入插入模式。
5. 输入 `#`。
6. 按 `<Esc>` 退出插入模式。

结果：

```
# line 1
# line 2
# line 3
```

## 多光标插件 (可选)

如果需要更接近 VS Code/Sublime 的多光标体验，可以考虑安装插件。

### `mg979/vim-visual-multi`

这是一个功能强大的多光标插件。

**基础配置快捷键 (示例 `lua/plugins/visual-multi.lua`):**

```lua
vim.g.VM_maps = {
  ["Find Under"] = "<M-d>", -- 选择光标下单词并选择下一个匹配 (Alt+d)
  ["Find Subword Under"] = "<M-d>",
  ["Select All"] = "<C-A>", -- (可选) 选择所有匹配
  ["Skip Region"] = "<C-x>", -- 跳过当前匹配
  ["Remove Region"] = "<C-p>", -- 移除上一个选择
}
```

**基本用法:**

1. 光标置于单词上。
2. 按 `<M-d>` (Alt+d) 选择并寻找下一个匹配。
3. 重复按 `<M-d>` 添加更多光标/选区。
4. 按 `<C-x>` 跳过，`<C-p>` 移除。
5. 选中后，使用 `c`, `I`, `A`, `d`, `y` 等命令进行编辑。
6. 按 `<Esc>` 退出。

### `nvim-pack/nvim-spectre`

这个插件更侧重于项目范围内的查找和替换，也支持多光标编辑。

根据你的需求选择是否安装和配置这些插件。
