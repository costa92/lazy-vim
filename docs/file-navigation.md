# Neovim 文件导航与位置跳转

本文档介绍 Neovim 中的各种文件导航和位置跳转功能，帮助您快速在项目和文件中移动。

## 文件查找与打开

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `<leader>o` | 打开文件 | 快速在项目中查找并打开文件（模糊查找） |
| `<leader>r` | 最近文件 | 打开最近编辑过的文件列表 (MRU) |
| `<C-e>` | 缓冲区列表 | 查看并切换当前打开的文件缓冲区 |

## 内容查找与跳转

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `<leader>f` | 全局搜索 | (live_grep) 在整个项目中搜索文本内容 |
| `<C-f>` | 当前文件搜索 | 在当前文件中搜索文本 |
| `<leader>s` | 语法树查找 | 通过 Treesitter 查找代码结构元素 |

## 代码导航 (LSP 功能)

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `gd` | 转到定义 | 跳转到符号定义处 |
| `gr` | 查找引用 | 查找符号的所有引用 |
| `gi` | 查找实现 | 查找接口的实现 |
| `K` | 显示信息 | 显示符号信息 (hover) |

## 窗口导航

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `<C-h>` | 左侧窗口 | 移动到左侧窗口 |
| `<C-j>` | 下方窗口 | 移动到下方窗口 |
| `<C-k>` | 上方窗口 | 移动到上方窗口 |
| `<C-l>` | 右侧窗口 | 移动到右侧窗口 |
| `sv` | 垂直分割 | 垂直分割窗口 |
| `sh` | 水平分割 | 水平分割窗口 |
| `sc` | 关闭窗口 | 关闭当前窗口 |
| `so` | 关闭其他 | 关闭其他窗口 |

## 位置标记与历史

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `<leader>m` | 标记列表 | 显示并跳转到已设置的标记 |
| `m` + `字母` | 创建标记 | 例如 `ma` 在当前位置创建标记 `a` |
| `` ` `` + `字母` | 跳转标记 | 例如 `` `a `` 跳转到标记 `a` |
| `<C-o>` | 跳回上一位置 | 在跳转历史中后退 |
| `<C-i>` | 跳至下一位置 | 在跳转历史中前进 |

## Git 导航

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `<leader>gp` | Git 提交 | 查看项目的 Git 提交历史 |
| `<leader>gb` | 文件 Git 提交 | 查看当前文件的 Git 提交历史 |
| `<leader>gs` | Git 状态 | 查看 Git 仓库状态 |

## 其他导航功能

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `<leader>h` | 搜索历史 | 查看搜索历史记录 |
| `<C-b>` | 文件树 | 打开/关闭 Neo-tree 文件浏览器 |

## 使用技巧

1. **模糊搜索**：在大多数 FzfLua 提供的搜索中，您可以输入模糊匹配模式。例如，搜索 `mdl cnfg` 可能会匹配 `models/config.js`。

2. **精确搜索**：在 live_grep (`<leader>f`) 中，您可以使用引号进行精确匹配，例如 `"exact phrase"`。

3. **正则表达式**：在 live_grep 中，您可以使用正则表达式，例如 `function\s+\w+\(`。

4. **标记技巧**：
   - 小写字母标记 (`a-z`) 是文件局部的
   - 大写字母标记 (`A-Z`) 是全局的，可以在不同文件间跳转
   - 特殊标记：`` ` `` (光标上一位置), `^` (上次插入位置), `.` (上次修改位置)
