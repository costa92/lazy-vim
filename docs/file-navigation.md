# Neovim 文件导航与位置跳转

本文档介绍 Neovim 中的各种文件导航和位置跳转功能，帮助您快速在项目和文件中移动。

## 文件查找与打开

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `<leader>o` | 打开文件 | 快速在项目中查找并打开文件（模糊查找） |
| `<leader>r` | 最近文件 | 打开最近编辑过的文件列表 (MRU) |
| `<C-e>` | 缓冲区列表 | 查看并切换当前打开的文件缓冲区 |

## 内容查找与跳转

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `<leader>f` | 全局搜索 | (live_grep) 在整个项目中搜索文本内容 |
| `<C-f>` | 当前文件搜索 | 在当前文件中搜索文本 |
| `<leader>s` | 语法树查找 | 通过 Treesitter 查找代码结构元素 |

## 使用技巧

1. **模糊搜索**：在大多数 FzfLua 提供的搜索中，您可以输入模糊匹配模式。例如，搜索 `mdl cnfg` 可能会匹配 `models/config.js`。

2. **精确搜索**：在 live_grep (`<leader>f`) 中，您可以使用引号进行精确匹配，例如 `"exact phrase"`。

3. **正则表达式**：在 live_grep 中，您可以使用正则表达式，例如 `function\s+\w+\(`。

4. **标记技巧**：
   - 小写字母标记 (`a-z`) 是文件局部的
   - 大写字母标记 (`A-Z`) 是全局的，可以在不同文件间跳转
   - 特殊标记：`` ` `` (光标上一位置), `^` (上次插入位置), `.` (上次修改位置)

## 打开文件并跳转到指定行

### 命令行方式

1. **打开文件到指定行**：

   ```
   :e filename +行号
   ```

   例如：`:e ~/.config/nvim/init.lua +10` 打开 init.lua 并跳转到第10行

2. **打开文件到指定行列**：

   ```
   :e filename +行号:列号
   ```

   例如：`:e ~/.config/nvim/init.lua +10:5` 打开 init.lua 并跳转到第10行第5列

3. **从终端命令行打开**：

   ```bash
   nvim filename +行号
   ```

   例如：`nvim ~/.config/nvim/init.lua +10`

### 在 FzfLua 中跳转到指定行

1. 在 FzfLua 文件查找 (`<leader>o`) 或缓冲区选择 (`<C-e>`) 中：
   - 选择文件后按 `<Alt-j>` 或 `<Tab>` 进入操作模式
   - 选择 "goto line" 选项
   - 输入行号回车即可

### 快速跳转技巧

- `数字G` 跳转到文件的第 "数字" 行 (例如：`10G` 跳到第10行)
- `gg` 跳转到文件第一行
- `G` 跳转到文件最后一行
- `:行号<CR>` 跳转到指定行号

## Neovim 中的特殊键盘符号

在 Neovim 的文档和配置中，经常出现一些特殊的键盘符号表示法。以下是常见符号及其含义：

| 符号 | 含义 | 键盘按键 |
|------|------|----------|
| `<CR>` | Carriage Return | 回车键 (Enter) |
| `<BS>` | Backspace | 退格键 |
| `<Tab>` | Tab | 制表键 |
| `<S-...>` | Shift + 键 | 例如 `<S-Tab>` 表示 Shift+Tab |
| `<C-...>` | Ctrl + 键 | 例如 `<C-n>` 表示 Ctrl+n |
| `<M-...>` | Meta (Alt) + 键 | 例如 `<M-j>` 表示 Alt+j |
| `<A-...>` | Alt + 键 | 与 `<M-...>` 同义 |
| `<D-...>` | Command + 键 (macOS) | 例如 `<D-s>` 表示 Command+s |
| `<leader>` | Leader 键 | 默认为 `\`，但在您的配置中设为空格键 |
| `<Esc>` | Escape | Esc 键 |
| `<Space>` | Space | 空格键 |
| `<Left>`, `<Right>`, `<Up>`, `<Down>` | 方向键 | 左、右、上、下方向键 |
| `<F1>` - `<F12>` | 功能键 | F1 到 F12 键 |

示例：

- `:行号<CR>` 意味着「输入冒号，然后输入行号，最后按回车键」
- `<C-w><C-h>` 意味着「按住 Ctrl 的同时先按 w，再按 h」

### 推荐配置（显示/复制当前文件相对路径）

```lua
vim.keymap.set("n", "<leader>fr", ':echo expand("%")<CR>', { desc = "显示当前文件相对路径" })
vim.keymap.set("n", "<leader>yr", [[:let @+ = expand("%")<CR>]], { desc = "复制当前文件相对路径" })
```

- `<leader>fr`（如空格+fr）：在命令行显示当前文件的相对路径。
- `<leader>yr`（如空格+yr）：复制当前文件的相对路径到系统剪贴板。
