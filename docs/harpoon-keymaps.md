# Harpoon 快速跳转

基于 `ThePrimeagen/harpoon`（harpoon2 分支）。用于**项目内 4-5 个热文件之间秒切**，比 FZF 每次搜索快得多。

## 核心用法

| 快捷键 | 功能描述 |
|--------|----------|
| `<leader>Ha` | 把当前文件加入 harpoon 列表 |
| `<leader>He` | 打开 harpoon 菜单（可编辑顺序/删除条目） |

## 跳转到固定槽位

| 快捷键 | 功能描述 |
|--------|----------|
| `<leader>1` | 跳转到槽位 1 的文件 |
| `<leader>2` | 跳转到槽位 2 的文件 |
| `<leader>3` | 跳转到槽位 3 的文件 |
| `<leader>4` | 跳转到槽位 4 的文件 |

## 循环切换

| 快捷键 | 功能描述 |
|--------|----------|
| `<leader>Hn` | 下一个 harpoon 条目 |
| `<leader>Hp` | 上一个 harpoon 条目 |

## 使用建议

1. 进入项目后，对你要反复编辑的 3-4 个文件各按一次 `<leader>Ha`
2. 之后全程用 `<leader>1/2/3/4` 秒切，不再靠记忆或 FZF
3. 在菜单（`<leader>He`）里可以手动调整顺序——把最常用的放槽位 1
4. Harpoon 列表**按项目分别持久化**，下次打开同一项目会恢复
