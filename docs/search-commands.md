# Neovim 搜索快捷键指南

本文档列出了所有与搜索相关的快捷键命令。这些命令基于 FzfLua 插件实现，提供了强大的模糊搜索功能。

## 全局文本搜索

| 快捷键 | 功能描述 |
|--------|----------|
| `<space>f` | 在整个项目中搜索文本内容（live_grep） |

## 文件搜索

| 快捷键 | 功能描述 |
|--------|----------|
| `<space>o` | 搜索并打开文件 |
| `<space>r` | 查看最近打开过的文件（MRU） |
| `<Ctrl>e` | 在已打开的文件（缓冲区）中搜索 |

## 历史记录

| 快捷键 | 功能描述 |
|--------|----------|
| `<space>r` | 打开最近使用的文件列表（MRU - Most Recently Used） |
| `<space>h` | 查看搜索历史记录 |
| `<Ctrl>e` | 显示当前打开的所有缓冲区列表 |

## 当前文件搜索

| 快捷键 | 功能描述 |
|--------|----------|
| `<Ctrl>f` | 在当前文件中搜索文本 |

## 特殊搜索

| 快捷键 | 功能描述 |
|--------|----------|
| `<space>s` | 使用 Treesitter 搜索代码结构 |
| `<space>h` | 查看搜索历史 |
| `<space>m` | 搜索文件中的标记点（marks） |

## Git 相关搜索

| 快捷键 | 功能描述 |
|--------|----------|
| `<space>gp` | 搜索所有的 Git commits |
| `<space>gb` | 搜索当前文件的 Git commits 历史 |
| `<space>gs` | 搜索 Git 状态变更的文件 |

## 使用说明

1. `<space>` 是 leader 键，在配置中被设置为空格键
2. 输入搜索命令后，会打开一个交互式的搜索窗口
3. 在搜索窗口中输入要搜索的内容，结果会实时显示
4. 可以使用上下键选择结果，Enter 键确认选择
5. 按 Esc 键可以关闭搜索窗口

## 历史文件操作说明

1. 最近文件（`<space>r`）：
   - 显示最近打开过的所有文件列表
   - 支持模糊搜索，输入文件名的一部分即可过滤
   - 列表按使用时间排序，最近使用的文件排在前面

2. 缓冲区列表（`<Ctrl>e`）：
   - 显示当前打开的所有文件
   - 可以快速在已打开的文件间切换
   - 支持模糊搜索和实时过滤

3. 搜索历史（`<space>h`）：
   - 显示之前执行过的搜索命令
   - 方便重复之前的搜索操作

## 常用组合

- `<space>f`：当需要搜索项目中的某段代码或文本时使用
- `<space>o`：当需要快速打开某个文件时使用
- `<space>r`：当需要打开最近编辑过的文件时使用

## 提示

- 所有搜索都支持模糊匹配，不需要输入完整的内容
- 搜索结果会实时更新，可以快速定位到需要的内容
- Git 相关搜索可以帮助快速查看代码变更历史
- 在任何搜索窗口中，都可以输入文件名或内容的一部分来过滤结果
